# lucanobilidavach.com

Personal portfolio of Luca Nobili D’Avach. Static site served by GitHub Pages (custom domain in `CNAME`).

## Structure

```
index.html                 the whole site: index, About me, and every project page
favicon.png
CNAME                      custom domain (do not delete)
assets/
  logos/                   project logos (SVG originals; the site uses inline copies)
  quercia/
    hero.mp4               background video after the first paragraph
    flyers/                FLYERS carousel, numbered in page order
    graphics/              GRAPHIC ASSETS carousel, numbered in page order
    stages/                STAGES carousel, numbered in page order
  isola/                   Isola di Mortorio main video + VHS series
  santi40/                 final shot, drawing, and previz.html (3D shot previz, embedded)
  samesations/             (Same)sations editorial shots
v1/                        archive of the previous site (lucanobilidavach.com/v1/)
```

Each video has a `.jpg` with the same name: that is its poster frame.
All media here are web-compressed copies; the full-quality originals live outside the repo.
